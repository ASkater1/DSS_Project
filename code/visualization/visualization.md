# Description

This is the actual dashboard itself, running the website one can access via a web browser.

## Current contents
Currently (13/10/2026 12:15) it contains the base dashboard as included in assignment 0.2, with some placeholder visualizations and proofs of concepts with the purpose of studying the functionality of streamlit.

## Added packages
pandas and numpy are currently included to form placeholder data using the .random functions and pd dataframes. These will probably not be necessary in the final version because the db container is ready by then.

## Expected folders:
There are no expected files required for this Container to run, as it will receive all data points from the database itself.

## Expected environment variables:
* DB_HOST
* DB_NAME
* DB_USER
* DB_PASSWORD
